# Changelog

## Portfolio modernisation

- Updated and trimmed dependencies, removed the EmailJS submission path and added a validated email draft with a direct mailto fallback.
- Preserved the dark space theme with a static starfield. Added responsive WebP imagery, project screenshots and prominent recruiter actions.
- Added keyboard navigation, focus management, labelled form feedback and mobile layouts tested at 320 px.
- Pre-rendered all public routes, generated share metadata and structured data, and added a Render Static Site Blueprint, security headers and a custom error page.
- Added strict type checks, ESLint, Prettier, Husky, Vitest, Playwright, Lighthouse CI and Dependabot.
